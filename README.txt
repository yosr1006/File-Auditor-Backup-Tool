# File-Auditor-Backup-Tool
Operating Systems - Bash mini project 

Description:
A Bash tool used to scan directories,
audit file permissions, count file extensions,
search for files, create backups and restore them.

Files:
- auditor.sh: Main program.
- lib.sh: Helper functions.
- sample_data/: Test directory.

How to run:
1. Make scripts executable:
chmod +x auditor.sh
chmod +x lib.sh

2. Run the interactive menu:
./auditor.sh sample_data

3. Run a specific action:
./auditor.sh sample_data scan
./auditor.sh sample_data perms
./auditor.sh sample_data ext
./auditor.sh sample_data backup
